LESSON 01

변수와 자료형

변수는 데이터를 담아 두는 이름입니다. JavaScript에서는 const와 let으로 변수를 선언할 수 있습니다.

const course = "JavaScript";
let lessonCount = 4;
LESSON 02

조건문

조건문을 사용하면 조건의 참·거짓에 따라 서로 다른 코드를 실행할 수 있습니다.

if (score >= 60) {
  console.log("합격");
}
LESSON 03

반복문

반복문은 같은 작업을 여러 번 실행할 때 사용합니다.

for (let i = 1; i <= 5; i++) {
  console.log(i);
}
